# Security Policy

## Reporting a Vulnerability

To report a security issue, please use GitHub's
[private vulnerability reporting](https://github.com/robotsix/ros2-example-interfaces/security/advisories/new)
or email [security@robotsix.org](mailto:security@robotsix.org) with details.

We will acknowledge your report within 5 business days and work to resolve the issue
promptly.

## Supported Versions

| Version   | Supported          |
|-----------|--------------------|
| `rolling` | :white_check_mark: |
| `jazzy`   | :white_check_mark: |
| `humble`  | :white_check_mark: |
